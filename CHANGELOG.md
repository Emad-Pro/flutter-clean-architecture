# Changelog

All notable changes to the "Flutter Arch Pro" extension will be documented in this file.

## [0.0.2] - 2026-03-18
### Added
- ✨ **Branding**: Added official extension icon (128x128).
- 👤 **Author Credits**: Integrated developer metadata and contact information.
- 🛡️ **Legal**: Added MIT License to the package.

### Changed
- 📝 Updated README with better installation instructions.
- 🚀 Optimized extension activation events for faster performance.

---

## [0.0.1] - 2026-03-18
### Added
- 🎉 **Initial Release**: Full support for Flutter Architecture generation.
- 🏗️ **Architectural Patterns**: Support for Clean Architecture, MVVM, MVC, and MVP.
- 🧪 **State Management**: Automatic folder generation for Bloc, Riverpod, GetX, and Provider.
- 📂 **Context Menu Integration**: Added "Generate Feature" and "Init Core" to the Explorer context menu.
- ⚙️ **Custom Configuration**: Added VS Code settings to set default architecture and state management.
- 🛠️ **Boilerplate Code**: Automated creation of Domain, Data, and Presentation layers.
